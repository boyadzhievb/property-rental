Property Rental — User Guide & Help

What Is Property Rental?

Property Rental is a personal property management app for short-term rental owners. It helps you manage rooms, guests, reservations, payments, and daily tasks from a single mobile-friendly interface.

All data stays on your device. There are no accounts, no cloud sync, and no external servers. Your information is completely private.

The app is available as a web app, an Android app on Google Play, and an iOS app on the App Store.

Getting Started — Create Your Property

When you open the app for the first time, the Welcome screen appears with three options:

Option A: Configure Manually

1

Enter your property name (e.g. "Villa Blanca").

2

Set the number of rooms.

3

Tap Configure App. Rooms are created automatically with default names, prices, and capacities that you can edit later.

Option B: Import a Backup

If you have a backup file from another device, tap Import Backup and select the JSON file. All your data will be restored.

Option C: Try with Demo Data

Tap Seed with Demo Data to load sample rooms, guests, and reservations so you can explore the app before entering real data.

Adding Rooms

1

Tap the Rooms tab at the bottom of the screen.

2

Tap the + Add button in the top right.

3

Enter the room name, price per night, and maximum number of guests.

4

Tap Add Room.

To edit a room, tap the pencil icon on its card. You can change the name, price, and capacity at any time.

Creating a Reservation

1

Tap the blue + button (visible in the bottom-right corner on every screen).

2

Select a guest from the list, or tap + New Guest to create one by entering their name, phone number, and optional email.

3

Tap Next.

4

Select a room by tapping its name. If the room has existing bookings, occupied dates are shown in red so you can avoid conflicts.

5

Pick the check-in and check-out dates, and set the number of guests.

6

Review or adjust the total price (auto-calculated from nights × room price).

7

Optionally set a repeat schedule (weekly, every 2 weeks, or monthly) for recurring guests.

8

Tap Save.

Editing or Cancelling a Reservation

Go to the Calendar tab and tap any reservation bar to open its details. From there you can record payments or cancel the reservation using the Cancel Reservation button.

Check-In and Check-Out

You can check guests in and out from two places:

From the Today Tab

The Today tab (your default landing screen) shows today's arrivals and departures.

1

Find the guest under Arrivals and tap Check In, or find them under Departures and tap Check Out.

2

Confirm when prompted.

Checking in a guest sets the room status to Occupied. Checking out sets it to Cleaning.

From the Calendar Tab

1

Go to the Calendar tab and tap the reservation bar.

2

Use the Check In or Check Out button at the bottom of the detail popup.

After Check-Out

When a room enters Cleaning status, a cleaning task is automatically created on the Today tab. Once you complete the cleaning task (or tap Mark as Cleaned on the Rooms tab), the room returns to Available and is ready for the next guest.

Offline Behavior

Property Rental works entirely offline after the initial load. All data is stored locally on your device using IndexedDB. You do not need an internet connection to use any feature of the app — creating reservations, checking guests in and out, recording payments, and managing tasks all work without connectivity.

The web version includes a service worker that caches the app for offline use. The Android and iOS versions are fully native apps that do not require an internet connection at all.

Backup and Restore

Since all data lives on your device, regular backups are recommended.

Export a Backup

1

Go to Settings.

2

Under the Data section, tap Export Backup.

3

A JSON file is saved to your device (Downloads folder on web, Documents folder on mobile).

Restore a Backup

1

Go to Settings.

2

Tap Restore Backup and select a previously exported JSON file.

3

Your data is replaced with the contents of the backup file.

Reset Data

To start fresh, tap Reset Data in Settings. A backup is automatically downloaded before the reset, so you can restore it later if needed.

Troubleshooting

The app shows a blank screen

Try closing and reopening the app. On web browsers, clear the site data for the app and reload. If you have a backup file, you can restore it after clearing the data.

I lost my data

If you exported a backup before the data was lost, go to Settings and tap Restore Backup to import the file. If you do not have a backup, the data cannot be recovered — the app stores everything locally on your device with no cloud copy.

Notifications are not working

Notifications are available on the native Android and iOS apps only (not on the web version). Go to Settings and make sure Enable Notifications is turned on. If notifications were previously denied, you need to enable them in your device's system settings for the Property Rental app.

The app is not updating

On the web, the service worker caches the app. Close all tabs running the app and reopen it to load the latest version. On Android and iOS, update the app through the respective store.

Import fails with an error

Make sure the file is a valid JSON backup exported from Property Rental. The file must have a .json extension and contain the expected data structure (rooms, guests, reservations).
