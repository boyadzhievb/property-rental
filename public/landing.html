Common questions

Is it really free?

Yes. The full app is free with all features included. No trials, no feature restrictions, no hidden charges.

Does it sync across devices?

Currently the app stores data on each device independently. You can use the backup/restore feature to transfer data between devices manually.

What happens if I lose my phone?

Use the export feature regularly to save a backup file. You can restore from that file on any device.

Can guests book rooms through this app?

No. This is an internal management tool for the property owner, not a public booking platform. You manage your bookings directly.

How many rooms can I manage?

There is no limit. The app is designed for properties with 1-10 rooms but works with any number.
